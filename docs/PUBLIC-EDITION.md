# 공개본 자료 범위

- 회사 프로젝트의 이미지, 고객명, 내부 설명과 계약·운영 수치는 포함하지 않습니다.
- UI Demo 1~6은 화면과 라우팅을 확인하기 위한 합성 데이터이며 실제 회사 프로젝트를 재현하지 않습니다.
- SVG 안내 이미지는 이 공개본에서 작성한 도형과 텍스트입니다. 원본 화면, 로고, 인물 사진은 사용하지 않습니다.
- Developer Portfolio 설명은 이 저장소의 코드로 확인할 수 있는 기능에 한정합니다.
- DB의 V3 지식 데이터는 합성 테스트 예제입니다. 운영 DB와 공유하지 마세요.
- 운영 workflow, App 인증, 서버 설정, 원본 이력서, 기존 Git 이력은 포함하지 않습니다.
- application-prod/production YAML은 테스트 리소스에만 존재하는 합성 보안 테스트 fixture입니다.
- 저장소의 Public 전환은 별도 사용자 결정이며 현재 저장소는 Private로 유지합니다.
