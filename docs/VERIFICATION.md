# 공개본 구성 및 로컬 검증

## 포함 범위

React/TypeScript 컴포넌트와 스타일, Spring Boot Controller/Service/Repository, 보안·입력 검증·요청 제한, 통계·챗봇 로직과 테스트를 선별했습니다. Gradle Wrapper JAR는 빌드 bootstrap에 필요한 유일한 바이너리입니다.

회사 원자료, 사진, 로고, 원본 문서, 고객명·성과 수치·내부 운영 설명, 운영 프로필·배포 도구·App 인증·기존 배포 workflow·기존 Git 이력은 복사하지 않았습니다. 운영 저장소의 파일은 수정하지 않았습니다.

## 공개본에서 변경한 부분

- 회사 사례 6개를 실제 기업과 관련 없는 UI Demo 1~6으로 바꾸고 라우트 ID도 project-one~project-six로 바꿨습니다.
- 회사 이미지와 프로필 사진을 자체 작성한 SVG 안내 이미지 3개로 대체했습니다.
- 프로필·기술 설명은 이 저장소에서 확인할 수 있는 내용으로 한정했습니다.
- 원본 회사 지식 seed를 11개의 합성 지식 예제로 교체했습니다. 운영 DB·Flyway 이력과 공유할 수 없는 별도 DB용 공개본입니다.
- UI/Markdown 테스트의 실제 회사 콘텐츠 기대값을 제거하고 합성 데이터에 대한 기존 동작 검증을 유지했습니다. 백엔드 테스트는 축소하지 않았습니다.
- 서버 profile 관련 보안 테스트는 테스트 전용 YAML fixture로 유지했습니다. 운영 설정 파일은 포함하지 않습니다.
- 비공개 정적 파일 차단 정책은 deploy 경로와 독립적인 frontend/config에 배치했습니다.
- 새 CI는 읽기 권한으로 빌드·테스트만 수행합니다. 운영 인증/배포/아티팩트 업로드 단계가 없습니다.

## 로컬 검증 결과

- npm ci: lockfile대로 설치.
- npm run test:all: UI·Markdown·개인파일 차단·챗봇·네비게이션·통계·progress/motion 전부 통과.
- npm run build:release: 콘텐츠 검사·TypeScript·Vite·빌드 전후 개인정보 파일 검사 통과.
- Java 21 gradlew test build: 136개 테스트, 실패/오류/스킵 0, 전체 빌드 성공.
- 백엔드는 H2와 모의 HTTP/Provider만 사용했습니다. 실제 Gemini나 운영 DB에 연결하지 않았습니다.
- 알려진 AWS/GitHub/Gemini 키, 실제 개인키 블록·JWT·인증 URL 및 운영 경로/저장소 식별 패턴 검사에서 차단 항목이 없었습니다.
- 일반 비밀번호/키 대입 후보는 환경변수 참조와 합성 테스트 값으로 확인했고, 이메일 후보는 example 도메인의 합성 테스트뿐이었습니다.
- SVG는 도형과 텍스트만 사용하며 외부 이미지 참조·스크립트가 없습니다.
- 배포물·node_modules·캐시·로컬 감사 결과는 Git에서 제외합니다. 초기 커밋에는 기존 .git 이력이나 운영 배포 workflow를 넣지 않습니다.

전용 secret scanner·의존성 CVE 검사·실제 브라우저 검증 및 운영 사이트 가용성 검증을 수행했다는 의미는 아닙니다. 검출되지 않은 비밀정보가 절대 없다고 보장하지 않습니다. Public 전환과 재사용 라이선스 결정은 소유자의 별도 검토 사항입니다.
